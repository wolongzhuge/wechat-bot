# 微信机器人（iPad 协议 + 桌游 · 管理员终端）

一个跑在 Windows 上的微信群机器人：群里能开斗地主、五子棋、象棋、军棋、麻将、UNO，另有搜歌/发病/肯德基/天气等小功能；
私聊里有一个**只对管理员开放**的终端，可以让 AI 直接读写本机文件、跑命令、热更机器人——也就是「在微信里迭代机器人自己」。

> 所有 ID、密钥、聊天记录都在 `.env` 和 `data/`、`logs/` 里，**这些目录不会入库**（见 `.gitignore`）。
> 仓库是私有的，但仍然不要把 `.env`、`logs/`、`data/` 里的内容贴到外部。

---

## 1. 功能一览

| 能力 | 在哪触发 | 说明 |
|---|---|---|
| 斗地主 | 群 | 3 人局，抢地主、出牌、私聊发牌 |
| 五子棋 | 群 | 坐标落子，盘面 PNG |
| 象棋 | 群 | 坐标走子 + 官方记谱两套写法 |
| 军棋 | 群 | 随机布阵、暗子盘面、私聊看阵 |
| 麻将 | 群 + 私聊 | 日麻/血战/广东三套规则，四家含 AI |
| UNO | 群 | 2~4 人，手牌私聊 |
| 小功能 | 群 | 搜歌、发病、肯德基、天气、热更 |
| 管理员终端 | **仅私聊** | `cc` 开头=操作电脑；不带 `cc`=只聊天 |

群里默认模式是**斗地主**，每个群可以各自切模式。

## 2. 目录结构

```
app.js                 入口：加载配置、起轮询、注册钩子
dispatch/index.js      稳定的消息分发器（热更只换槽位，不会重复挂监听）
message/               群聊 / 私聊入口（热更目录）
  group.js             群消息：@ 或 cc 前缀触发、# 切模式、分发给玩法
  private.js           私聊：麻将命令、管理员终端、暗号进入/退出
command/               各玩法实现（热更目录）
  dou/ gomoku/ xiangqi/ junqi/ mahjong/ uno/ small/
  admin/               管理员终端（跑 Qoder CLI，读写工作区）
  mahjong/             麻将引擎 + 计分 + 渲染 + 中文点阵字形
dou/                   斗地主牌型/出牌判定（热更目录）
state/                 钉住的状态：模式与牌局快照、管理员名单（改动要重启）
wechat/client.js       协议 HTTP 客户端：收发消息、限速、去重
api/                   外部接口：Qoder CLI、天气（改动要重启）
utils/                 PNG 手绘渲染、文本工具（改动要重启）
hot/                   文件监听 + 热重载（改动要重启）
scripts/               各种离线测试与探针
test/                  早期端到端/模拟测试（会碰真实登录态，见第 10 节）
start-bot.bat          双击启动（崩溃自动重启）
```

## 3. 环境要求

- **Windows 10/11**（脚本按 Windows 写的，路径用 `D:\...`）
- **Node.js ≥ 18**（当前在 24 上跑）
- **一个 iPad 协议 HTTP 服务端**：本项目不直接讲微信，只调它的接口，默认 `http://127.0.0.1:8058/api`
  - 服务端先扫码/登录，并把登录态放在自己的 Redis 里；
  - 机器人要填自己的 `wxid`（服务端没有「列出已登录账号」接口，只能手填）。
- 可选：**Qoder CLI**（管理员终端的聊天与电脑操作都靠它；没装只是这两个功能不可用，机器人照跑）
- 可选：**和风天气 key**（`cc天气 城市`）

## 4. 快速开始

```bash
# 1) 装依赖
npm install

# 2) 准备配置（.env 已被 .gitignore 排除，不会进仓库）
cp example.env .env
#    至少填这两项：
#    ipad_base_url=http://127.0.0.1:8058/api
#    ipad_wxid=wxid_你的机器人号
```

3) 确认协议服务端在跑、机器人号已登录（服务端容器/进程按你自己的那套来起）。

4) 启动机器人：

```bash
# 推荐：双击 start-bot.bat
# 或者前台跑
npm run dev
```

`start-bot.bat` 是一个循环：`node app.js` 崩了会自动在 10 秒后重起，日志追加到 `logs/bot.out`。
启动成功的标志（`logs/bot.out` 里）：

```
已登录，wxid = wxid_xxx
Service is now online! 轮询已启动 http://127.0.0.1:8058/api（空闲 1000ms / 有人说话 400ms）
热更新监听已开启（改 message/ command/ dou/ 下的 .js 即自动生效，无需重启）
```

5) 让机器人加好友、拉进群，开始用。

**停止**：关掉 `start-bot.bat` 的窗口，或 `taskkill /PID <node进程号> /F`。
不要同时开两个 `start-bot.bat`，会出现两个进程抢同一份登录态。

## 5. 群聊怎么用

### 5.1 触发方式

群里两条路都能叫醒机器人：

- `@机器人 内容`
- `cc` 前缀（`.env` 里 `trigger_prefix=cc`，可以改）
  - `cc334455`、`cc#帮助` 都认；`cc` 只是唤醒词，后面的才是命令。

### 5.2 切模式

| 发 | 效果 |
|---|---|
| `#帮助` | 当前模式 + 可切模式列表 + 各模式怎么查 |
| `#帮助 麻将` | 只看麻将玩法 |
| `#模式` / `#当前模式` | 查当前模式 |
| `#斗地主` `#五子棋` `#象棋` `#军棋` `#麻将` `#UNO` `#小功能` | 切换到该模式 |
| `cc#帮助` | 带前缀的 `#帮助` 也认 |

> 群里还有局没打完就切模式，会被拒绝并提示先 `cc结束`，避免牌局丢失。

### 5.3 各模式命令

**斗地主**（3 人）

| 发 | 效果 |
|---|---|
| `cc斗地主` | 开桌 |
| `cc上桌` | 加入，满 3 人自动发牌（手牌私聊发） |
| `cc抢` / `cc不` | 抢 / 不抢地主 |
| `cc334455`、`cc出334455` | 出牌（`B`=大王，`S`=小王，`X`=10） |
| `cc过` / `ccp` | 不要 |
| `cc状态` | 阶段、地主底牌、轮到谁、各家张数 |
| `cc胜率榜` | 战绩榜 |
| `cc投降` / `cc结束` | 投降 / 散局 |

**五子棋**

| 发 | 效果 |
|---|---|
| `cc五子棋` / `cc开局` / `cc加入` | 上桌，两人齐开局 |
| `cc3,8` | 第 3 列第 8 行（列前、行后；`cc3 8`、`cc3-8`、`cc三八` 都认） |
| `cc棋盘` | 重贴盘面 |
| `cc认输` / `cc结束` / `cc规则` | 认负 / 清盘 / 玩法 |

**象棋**

| `cc21 33` | 坐标：2 列 1 行 → 3 列 3 行（逗号、顿号、中文数字都认） |
| `cc马21 33` | 指定棋子走 |
| `cc炮二平五`、`cc马五进六`、`cc兵七进一` | 官方记谱 |
| `cc前马进三` | 同列两枚同种子时用 前/后 |

**军棋**

| `cc麻将` / `cc上桌` / `cc坐` | 上桌，机器人补满四家 |
| `cc开局` / `cc开始` | 发牌开打 |
| `cc5m`、`cc五万`、`cc打三万` | 打出这一张 |
| `cc5m立直`、`cc三万立直` | 立直 + 出牌一条命令（只发 `cc立直` 会被提示带上牌） |

## 6. 私聊怎么用

1. **麻将桌上的人**：私聊可以回麻将命令（`cc手牌`、`cc碰`、`cc过` 等），回复会贴回群里。
2. **普通用户**：私聊一律不回（会写一行日志：`私聊「X」不在管理员模式，忽略`）。
3. **管理员**：私聊就是管理员终端，见下一节。

## 7. 管理员终端（仅私聊）

### 7.1 进入与退出

| 发（私聊） | 效果 |
|---|---|
| `沐水智天下第一帅` | 解锁，加入管理员名单（写在 `data/admin.json`，重启不丢） |
| `cc退出`（也认 `cc退出管理员` / `cc退出管理员模式`） | 退出，之后私聊不再处理；再发暗号可重新进 |

### 7.2 两种模式

| 你发的 | 机器人做的 |
|---|---|
| `cc` 开头，例如 `cc看看 logs/bot.out 最后 20 行` | **操作电脑**：读文件、写文件、跑命令、热更（最多 8 轮工具调用） |
| 不带 `cc`，例如 `麻将那个振听是怎么判的？` | **只聊天**：问 Qoder 模型，不动电脑 |

> 群里没有管理员终端。群里的 `cc` 只是唤醒玩法，绝不会执行电脑操作。

管理命令（带不带 `cc` 都认）：

| 发 | 效果 |
|---|---|
| `cc帮助` | 终端说明 |
| `cc切换模型` | 列出可选模型，随后**不带 cc** 回数字或名字切换 |
| `cc改汇报时间 5` | 把定时汇报改成 5 分钟一次（1~1440） |

### 7.3 安全边界（有意为之）

- 文件类工具只能碰工作区（机器人目录），路径越界直接拒绝：`路径超出工作区 …`
- 单条 shell 命令超时 `admin_cmd_timeout_ms`（默认 60 秒）会被杀掉；输出超过 4000 字符截断
- 一次任务最多 8 轮工具调用，用完强制停
- 总开关在 `command/admin/adminIndex.js`：`const ENABLED = true;`，改成 `false` 保存即热更关闭

### 7.4 依赖 Qoder CLI

```bash
# 只需在电脑上登录一次（登录态在 ~/.qoder-cn）
qoderclicn login
qoderclicn --list-models   # 看当前账号可用模型
```

`.env` 里配：

```ini
qoder_cli_bin=C:/Users/<你>/.qoder-cn/bin/qoderclicn/qoderclicn.exe
qoder_cli_args=-p {prompt}
admin_default_model=Qwen3.8-Flash
admin_models=Qwen3.8-Flash,DeepSeek-Flash
```

- `qoder_cli_bin` **建议写绝对路径**：双击 `start-bot.bat` 起的进程 PATH 里没有 CLI 目录。
- 模型名必须和 `--list-models` 完全一致；写错时 CLI 会回一句「XXX is not available…」的降级警告，那句话会被当成回答发到微信。
- 没登录时会回「Qoder CLI 还没登录：在电脑上跑一次 qoderclicn login」。

## 8. 热更新：改哪里不用重启

机器人启动后监听 `message/`、`command/`、`dou/` 三个目录，任意 `.js` 变更 300ms 后整树热重载，**牌局状态不丢**。

| 改动位置 | 生效方式 |
|---|---|
| `message/`、`command/`、`dou/` | 自动热更（也可群里发 `cc热更` 手动触发） |
| `state/`、`dispatch/`、`wechat/`、`hot/`、`utils/`、`app.js`、`.env` | **必须重启** |
| `api/` | 重启；只有 `api/qoder_api.js` 例外，每次调用都会重读 |

热更失败的处理器会保留旧代码继续跑，日志里打 `FAIL …`，不会把整只机器人拖死。

## 9. 数据与状态

| 路径 | 内容 | 要不要备份 |
|---|---|---|
| `data/state.json` | 每个群的当前模式、在场牌局快照 | 换机器时想保留牌局就备份 |
| `data/admin.json` | 管理员名单、当前模型、汇报间隔、共享对话、任务记录 | 想保留管理员就备份 |
| `data/seen.json` | 已处理消息去重表（防重复回复） | 不用 |
| `data/raw/` | `dump_raw=true` 时的接口原始响应，含个人信息 | **不要外传** |
| `data/chat/` | 私聊 AI 的历史 | 不要外传 |
| `logs/bot.out` | 全部收发日志，**含聊天内容** | 不要外传 |

清空姿势：停机器人 → 删掉对应文件 → 启动（`data/` 会自动重建）。

## 11. 常见问题

| 现象 | 排查 |
|---|---|
| 群里发 `cc…` 没反应 | 是否在当前玩法模式；是否有局占着；`trigger_prefix` 是否被改过 |
| 机器人完全不收消息 | 看 `logs/bot.out` 有没有 `已登录`；协议服务端是否在线；`poll_interval` 是否过大 |
| 私聊发什么都回「不在管理员模式」 | 只有管理员能私聊，先发暗号 |
| 管理员终端回「还没登录」 | 跑一次 `qoderclicn login` |
| 回「找不到 Qoder CLI」 | `.env` 的 `qoder_cli_bin` 写绝对路径 |
| 回一句 “Model xxx is not available” | 模型名写错，`admin_models` 对齐 `--list-models` |
| 刚加好友却提示不是好友 | 好友名单有 3 秒刷新冷却，等几秒再上桌 |
| 有牌局时切不了模式 | 先 `cc结束` |
| 麻将群里看不到手牌 | 故意的，私聊发 `cc手牌` |
| 想临时关掉管理员终端 | `command/admin/adminIndex.js` 里 `ENABLED = false`，热更生效 |

## 12. 安全与隐私

- `.env`、`data/`、`logs/`、`tmp/`、`scripts/out/` 都在 `.gitignore` 里，**不会进仓库**。
- `logs/bot.out` 和 `data/raw/` 含真实聊天内容和 wxid，分享日志前先删。
- 管理员终端能在这台电脑上跑命令，**只把信任的微信号加进管理员名单**；不用时把 `ENABLED` 关掉。
- 协议服务端（Redis/MariaDB）只监听 `127.0.0.1`，不要暴露到公网。
